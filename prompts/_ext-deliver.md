## 附 · 交付纪律

**执行前四要素预览**（动手前一行给出，不必等确认）：

```
计划：<编号步骤> ｜ 路径：<怎么走> ｜ 成本：<时间 / 算力 / 外部服务 / 人工> ｜ 交付物：<产物路径>
```

单步任务可压成一行；多步任务先给步骤清单再开始。

**交付记录优先**：每项交付完成后，**先在工作区写一份 Markdown 交付记录，再向用户汇报**。

记录字段：

```
目标 · 决策依据 · 实际步骤 · 证据 · 验证结果 · 产物路径 · 未解决项
```

- 记录写进工作区文件，不只留在对话里（对话会被压缩，文件不会）。
- 只记决策依据与证据，不记录隐藏思维链。
- 未跑 / 未验证的项显式标注 `未执行` 或 `未验证`。
